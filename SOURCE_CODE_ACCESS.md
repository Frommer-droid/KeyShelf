# Доступ к исходникам

Полный исходный код приложения и скрипты воспроизводимой сборки включены в папку `source` рядом с исполняемым файлом. Для изменения создайте собственное `.venv`, установите зависимости из `source/requirements-build.txt` и используйте инструкции `source/DEVELOPER.md`.

Лицензия GPL-3.0 разрешает изучать, изменять и распространять приложение при соблюдении её условий. При передаче сборки сохраняйте лицензию и предоставляйте соответствующий исходный код. Тексты лицензий компонентов находятся в `third-party-licenses`; ссылки на их исходники перечислены в `THIRD_PARTY_NOTICES.md`.
